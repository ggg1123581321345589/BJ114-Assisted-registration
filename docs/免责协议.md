# 免责协议

适用版本：辅助挂号软件 v1.1.1。

本软件为非官方辅助工具，供用户本人查询号源并在人工确认后提交一次预约，不保证号源可用或挂号成功。请遵守医院及官方平台规则，核对就诊人、就诊卡、日期、费用及取退号要求；预约和支付结果以官方平台为准。验证码须由本人输入，遇到提交结果未知时请先核对官方订单，勿重复提交。请妥善保护个人信息，勿用于倒号、代抢或其他违规用途。

## 使用前核对

- 仅在本人有权使用的账号、就诊人和就诊卡范围内操作，遵守医院和官方平台规则。
- 每次提交前确认医院、科室、医生、日期、时段、费用和就诊信息。软件不代替医疗判断。
- 短信、验证码、登录、预约确认和支付均由本人决定；当前没有定时提交功能。
- 遇到超时、网络错误或结果未知时，先到官方平台核对订单与支付状态，再决定下一步，避免重复预约或支付。
- 妥善保管手机号、身份信息、Cookie、令牌、就诊卡和订单；不要把抓包、协议记录或个人数据上传到公开仓库。

## 功能与验证边界

本地目录快照不代表实时号源。离线模拟和格式测试只能验证对应本地行为，不能据此保证网站可用或预约成功。取号、取消、退款和支付要求以官方平台当时公布的信息为准。

连接“就绪”只是本地会话状态，不是实时 TCP 探活。后台准备、补连、备用轮换和 DNS 地址缓存不能保证下一次请求成功或固定耗时；失败的业务查询和订单不会由补连机制自动重发。查询时间按北京时间（UTC+8）显示。本版没有进行真实预约提交测试，也未在全新 Windows 虚拟机中测试。
